# Touch Bar 小龙猫

把一只小龙猫养在 MacBook Pro 的 Touch Bar 上。它会四处走走、低头嗅闻、停下来理毛，饿了抱着草啃，渴了凑近水嘴喝水。沙浴时先伏低，再侧身翻滚、撑起身体；累了就蜷进小窝休息。

放好牧草、水、沙盘和玩具，它会根据饱足、饮水、精力、整洁和熟悉度选择活动。精力不足时，动作节奏会慢下来；照料与被接受的抚摸，也会让它逐渐熟悉你。熟悉之后，点一下空白处，它更愿意先看看，再走过来。

当前版本 **1.13.4**，支持 Intel 与 Apple 芯片。[下载安装包](https://github.com/linxitong98-rgb/TouchBarChinchilla/releases)

## 和它相处

左侧图标可以点选后放置，也能直接拖出。草、沙盘、小球、睡窝和喂水器可以同时摆着，位置随时可调，拖回物品框就能收起；除了牧草，其余各保留一件。物品放好后，由它自己选择什么时候过去。

没有选物品时，轻点龙猫就是摸摸，点空白处则是邀请它靠近。它有时会接受，有时只观察或退让；正在吃喝、沙浴或睡觉时，会先完成眼前的事。

喂水器放出后，图标会变成“水滴＋”，放到喂水器处就能补水。它也会不定期留下便粒，用物品框里的清洁铲点一下或拖过地面，就能整理干净。图标下的进度条显示照料状态，窗口和 Touch Bar 共享同一只龙猫。

持续快速触摸会让它戒备，熟悉度较低时可能喷尿警告、抛掷便粒或短暂装死。普通单次轻触不会直接触发这些反应，防御动作结束后会自行恢复活动。喷尿参考现实防御行为；抛掷便粒和装死是游戏化效果，具体规则见 `User-Guide.md`。

1.13.4 修复了小球卡在两侧边缘的情况。现在它会收步、走到球的另一侧，再自然转身往回顶；拖到边缘的小球也能继续玩，体型和动作衔接保持稳定。

## 下载与使用

在 [版本发布页](https://github.com/linxitong98-rgb/TouchBarChinchilla/releases) 下载 `TouchBarChinchilla-1.13.4-universal.dmg`，打开后把 App 拖入“应用程序”。更新前先退出旧版。操作细节见附件 `User-Guide.md`，校验值见 `SHA256.txt`；安装请选择 DMG，Source code 是仓库文件。

App 默认留在菜单栏，预览窗口可以隐藏。状态自动保存在本机，支持备份、恢复和布置撤销；关闭期间不消耗状态。没有 Touch Bar 的 Mac 也可在窗口中互动。

最低编译目标为 macOS 11。当前采用本地临时签名，尚无 Apple Developer ID 签名或 Apple 公证；Touch Bar 常驻依赖未公开接口，可能受系统版本及其他工具影响。写实素材由图像生成制作，并非实拍或动作捕捉；实体 Touch Bar 的触摸手感、持续帧率及旧系统兼容性仍需对应设备验证。
