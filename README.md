# Touch Bar 小龙猫

一只生活在 MacBook Pro Touch Bar 上的写实风格龙猫。它会走动、低头嗅闻、理毛、抱草进食、贴着水嘴喝水，也会在沙盘里翻滚，或蜷进小窝休息。

把草、水、沙盘和玩具放好后，它会根据自己的状态选择去哪里。你可以轻点它进行抚摸，也可以在空白处邀请它走近。熟悉度低时，它可能先观察或退让；熟悉之后，会更愿意主动靠近。精力不足时，活动节奏也会逐渐放缓。

当前版本 **1.13.2**，提供 Intel 与 Apple 芯片通用安装包。[前往下载](https://github.com/linxitong98-rgb/TouchBarChinchilla/releases)

## 动作与日常行为

- **走动与观察**：有起步、交替步伐、停步和转身过程，尾巴随身体转向；也会停下来探头嗅闻或整理毛发。
- **进食与饮水**：走到牧草旁抱草啃食，未吃完的草会保留；饮水时靠近悬挂喂水器，将嘴对准水嘴。饱足和饮水状态随过程逐渐恢复。
- **沙浴**：先伏低、贴近沙面，再侧身翻滚，最后撑起身体、收腿站稳。伏低、翻滚和起身之间使用过渡画面衔接。
- **休息**：疲倦时更倾向寻找睡窝，逐渐蜷起身体；醒来后再衔接起身与走动。精力在休息过程中恢复。
- **保持完整显示**：在不裁切耳朵、尾巴和脚部的前提下尽量放大。不同姿势共用身体缩放，转身和动作切换时保持体型稳定。

## 怎么互动

左侧物品框依次提供牧草、沙盘、小球、睡窝、悬挂喂水器和清洁铲。

1. **放置物品**：点选图标，再点空白处放下；也可直接从物品框拖出。放置后，龙猫会自行决定何时过去使用。
2. **调整位置**：场景物品可以拖动，拖回物品框即可收纳。沙盘、小球、睡窝和喂水器各保留一件，牧草可以放多份，所有物品可同时存在。
3. **抚摸与邀请**：未选物品时，轻点龙猫就是抚摸；点空白处则是邀请。熟悉度较高且状态允许时，它会先观察，再走近。正在吃喝、沙浴或睡觉时，会先完成当前行为。
4. **补水**：喂水器放出后，水滴图标变成“水滴＋”。点选后轻点喂水器，或把图标拖到喂水器处，即可补满。
5. **清理便粒**：龙猫活动时会不定期排便。点选清洁铲后点便粒、拖过地面，或将铲子从物品框拖到便粒处，都可以清理；清理脚边的便粒不会被误判为抚摸。

图标下的进度条显示照料状态。物品框贴在最左侧，为龙猫保留更多活动空间。

## 五项状态如何影响行为

| 状态 | 行为变化 |
| --- | --- |
| 饱足 | 饥饿时更倾向寻找牧草，进食后逐渐恢复 |
| 饮水 | 口渴时更倾向寻找喂水器，需要水源且瓶中有水 |
| 精力 | 影响走动速度、动作节奏和休息倾向，变化经过平滑处理 |
| 整洁 | 影响使用沙盘的意愿，沙浴后逐渐恢复 |
| 熟悉度 | 影响主动靠近、观察、退让，以及是否接受抚摸 |

抚摸被接受时，熟悉度增加8个百分点；平静观察且没有明显戒备时增加5个百分点。近期由你投放物品或补水后，完成吃草、饮水、沙浴和玩球，分别可增加4、3、2、2个百分点。这些增益仍受冷却与情绪条件限制，熟悉度最高100%。

## 持续打扰时的反应

连续、快速地触摸会累积戒备。满足触发条件时，熟悉度每次下降10个百分点，并有至少5秒的更新间隔。特殊防御按当时的熟悉度选择：

| 熟悉度 | 可能的反应 |
| --- | --- |
| 70%及以上 | 观察或退让，不触发特殊防御 |
| 50%～不足70% | 喷尿警告 |
| 30%～不足50% | 喷尿或抛掷便粒 |
| 低于30% | 喷尿、抛掷便粒或短暂装死 |

普通单次轻触不会直接触发特殊防御。同一档内随机选择，每次防御只选择一次，保留10秒冷却；继续点击不会重抽反应或重启动作，结束后会自行恢复。抛出的便粒落地后也可用清洁铲清理。

喷尿警告参考龙猫的防御行为；抛掷便粒和装死是游戏化效果，不代表真实龙猫的典型习性。五项指标、熟悉度阈值和时间间隔也是模拟参数，不能用于判断真实动物的健康状态。

## 1.13.2 更新

喷尿增加了更清楚的弧线喷流、亮芯、移动水滴、落点飞溅与渐隐。喷尿、抛掷便粒和装死会根据左右触碰确定朝向；点身体中央时保持已有朝向，先完成转身和姿势衔接再开始反应。

抛物起点对齐前爪附近，靠近边缘时仍向对应方向落地；喷流距离随可用空间调整。保留原有体型与动作素材，动作中途不会因继续触碰而突然翻面。

## 下载与安装

在 [版本发布页](https://github.com/linxitong98-rgb/TouchBarChinchilla/releases) 下载 `TouchBarChinchilla-1.13.2-universal.dmg`，打开后将 App 拖入“应用程序”。更新前先退出旧版，再启动新版。GitHub 自动生成的 Source code 是仓库文件，安装请选择 DMG。

最低编译目标为 macOS 11。配备 Touch Bar 的 MacBook Pro 可使用触控栏场景；其他 Mac 可在窗口中预览与互动。窗口与 Touch Bar 共享同一只龙猫及物品。状态自动保存在本机，支持备份、恢复和布置撤销；关闭 App 期间不消耗状态。

App 默认留在菜单栏，预览窗口可以隐藏。Touch Bar 常驻依赖 macOS 未公开接口，属于实验功能，不适用于 Mac App Store；系统升级或其他 Touch Bar 工具可能影响显示。

当前安装包采用本地临时签名，尚无 Apple Developer ID 签名或 Apple 公证。写实素材由图像生成制作，并非实拍或动作捕捉。实体 Touch Bar 的触摸手感、持续帧率、长期跨应用显示及旧系统兼容性，仍需对应设备验证。

完整操作说明见版本附件 `User-Guide.md`，安装包校验值见 `SHA256.txt`。
