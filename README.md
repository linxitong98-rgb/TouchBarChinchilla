# Touch Bar 小龙猫

为 MacBook Pro Touch Bar 制作的写实风格宠物龙猫。当前版本 **1.11.1**，同时支持 Intel 和 Apple 芯片。

![Touch Bar 实际视图渲染预览](touchbar-preview.png)

## 下载与安装

请到本仓库的 **Releases** 页面下载 `TouchBarChinchilla-1.11.1-universal.dmg`，打开后将 App 拖入“应用程序”。也提供可直接解压的 App ZIP。更新前请先退出旧版。

最低编译目标为 macOS 11；实体 Touch Bar 需要配备 Touch Bar 的 MacBook Pro，其他 Mac 可使用窗口预览。旧系统实际运行仍需相应设备验证。

## 玩法

- 点击左侧图标，再点空白处投放物品；也可直接拖出。
- 牧草、沙盘、小球、睡窝和悬挂喂水器可以同时存在；不可消耗物品各保留一件。
- 龙猫会根据需求自主吃草、饮水、沙浴、玩球和入窝休息。
- 拖动物品可重新布置，拖回物品框即可收纳；直接触摸龙猫是摸摸。
- 图标下的进度条显示照顾状态；物品框贴左，尽量保留活动空间。
- 自动保存本机状态，支持备份、恢复与布置撤销。

## 常驻与验证范围

App 默认留在菜单栏，可隐藏预览窗口。Touch Bar 常驻依赖 macOS 未公开接口，属于实验功能，不适用于 Mac App Store；系统升级或其他 Touch Bar 工具可能影响显示。

本版本采用本地临时签名，尚未取得 Apple Developer ID 签名和 Apple 公证。素材为生成的写实图像，并非实拍或动作捕捉。实体 Touch Bar 的实际触摸、帧率及长期跨应用显示仍需设备验证。

详细操作见版本附件中的《使用说明.md》。
