**方寸之间，自有生趣。**

让一只写实风格的小龙猫，陪伴于指尖。缓步探看、抱草细嚼、沙浴翻滚、蜷窝安睡——日常照料与轻轻问候，让这处小小居所渐添生趣。

1.13.2 细化了警示反应与左右朝向，让回应更清晰，动作衔接也更从容。

## 本版细节

- **水光更清晰**：警示喷流加入明亮弧线、散落水滴、落点飞溅与柔和渐隐，在 Touch Bar 的方寸空间里更容易辨认。
- **回应有方向**：三种防御反应随左右触碰确定朝向；轻点身体中央时维持原有朝向，过滤细小点击偏差。
- **衔接更自然**：先顺势转身，再作回应；持续触碰不会让同一段动作突然翻面或重新开始。
- **轨迹更贴合**：抛物从前爪附近出发，靠近边缘时仍向对应方向落地；喷流距离随可用空间调整。
- **熟悉的相伴仍在**：保留原有体型与动作素材，以及自主活动、熟悉度变化、环境清理、补水与旧存档兼容。

警示喷流参考龙猫的防御习性；抛掷便粒与短暂仰卧静止（装死）是游戏化演绎。普通单次轻触不会直接触发特殊防御，原有触发条件与冷却规则继续保留。

## 下载与使用

下载下方 `TouchBarChinchilla-1.13.2-universal.dmg`，打开后将 App 拖入“应用程序”。更新前请先退出旧副本，再启动新版。

完整中文说明见 `User-Guide.md`，安装包校验值见 `SHA256.txt`。GitHub 自动生成的 Source code 是仓库文件，安装请选择 DMG。

安装包同时包含 Intel 与 Apple 芯片版本，最低编译目标为 macOS 11。当前采用本地临时签名，尚无 Apple Developer ID 签名或 Apple 公证；Touch Bar 常驻依赖未公开接口。

已检查左右回应、动作衔接、边缘轨迹、连续运行与完整显示，并检视原生30点高的场景预览。实体 Touch Bar 的持续帧率与触摸手感，仍需对应设备验证。
