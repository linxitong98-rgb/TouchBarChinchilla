1.12.0 将五项状态更细致地关联到选择、互动和动作节奏。

## 本版更新

- 熟悉度影响观察、接受轻抚、退让，以及主动走近最近触碰过的位置。
- 连续快速打扰会增加短期戒备，安静后逐渐缓和；睡觉或忙于进食时会更倾向先完成当前行为。
- 精力平滑影响步速、部分动作节奏和休息倾向，脚步仍由实际位移推进。
- 饱足、饮水和整洁共同影响需求优先级，吃草、沙浴与休息的状态恢复逐步进行。
- 保留原体型标定和动作过渡；跳跃中收到触摸、引导或安静模式指令，会先落地再回应。
- 部分牧草可保存，撤销与重做不会补回已消耗的部分；兼容旧版存档，保留水滴＋加水玩法。

## 下载与安装

下载下方 `TouchBarChinchilla-1.12.0-universal.dmg`，打开后将 App 拖入“应用程序”。更新前先退出旧版。安装包支持 Intel 和 Apple 芯片，最低编译目标 macOS 11。

`User-Guide.md` 是完整中文说明，`SHA256.txt` 用于校验安装包。GitHub 自动生成的 Source code 是仓库文件，安装请选择 DMG。

本包采用本地临时签名，未取得 Apple Developer ID 签名或 Apple 公证。Touch Bar 常驻仍依赖未公开接口；实体硬件的触控手感、帧率和旧系统兼容性需相应设备验证。行为参数属于宠物模拟，不是动物生理测量值。
